========================================================================================
                                GLOBAL EXCEPTION HANDLING
========================================================================================

  +---------------------------+--------------------------------------------------------+
  | Exception Type            | Handling Behavior                                      |
  +---------------------------+--------------------------------------------------------+
  | FileNotFoundException     | Handled in Main (TableMappings.csv or Tables.csv       |
  |                           | missing from AppContext.BaseDirectory)                 |
  | InvalidDataException      | Handled in Main (Invalid CSV headers, row counts,      |
  |                           | port/server type, or 'y'/'n' console prompt input)     |
  | InvalidOperationException | Handled in Main (Duplicate destination table, self-    |
  |                           | referencing FK, or circular FK cycle) AND caught       |
  |                           | locally per-table in MigrateTablePair (0 columns)      |
  | DbException               | Caught locally per-table in MigrateTablePair           |
  |                           | (Covers both SqlException and NpgsqlException)         |
  | TimeoutException          | Caught locally per-table in MigrateTablePair           |
  | Exception (Catch-All)     | Caught locally per-table in MigrateTablePair AND       |
  |                           | globally in Main to ensure graceful termination        |
  +---------------------------+--------------------------------------------------------+
