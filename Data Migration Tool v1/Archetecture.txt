========================================================================================
                               GLOBAL EXCEPTION HANDLING
========================================================================================

  +---------------------------+--------------------------------------------------------+
  | Exception Type            | Handling Behavior                                      |
  +---------------------------+--------------------------------------------------------+
  | FileNotFoundException     | Handled in Main (JSON config or CSV missing)           |
  | JsonException             | Handled in Main (Malformed JSON file)                  |
  | InvalidDataException      | Handled in Main (Corrupt / invalid CSV layout)         |
  | SqlException              | Caught locally per-table in MigrateTablePair,          |
  |                           | and globally in Main for connection open failures      |
  | TimeoutException          | Caught locally in MigrateTablePair                     |
  | InvalidOperationException | Caught locally in MigrateTablePair & globally in Main  |
  +---------------------------+--------------------------------------------------------+
